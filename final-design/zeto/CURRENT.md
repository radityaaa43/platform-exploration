## 5. Who may mint, burn, move
- Mint: only the token `owner()` (BI's node1 address): `function mint(...) public virtual onlyOwner` zeto@v0.5.1 solidity/contracts/lib/zeto_common.sol:106-109. Lensa issues by BI minting private UTXOs to a bank: besu/zeto/src/flows.ts:76-81 (`mintUtxos`), frontend zeto.ts `flow.issuer && !flow.dvp` branch.
- Burn / redeem: `withdraw` by a holder (zeto_fungible.sol:321) and `deposit` (:264) need `setERC20` (`onlyOwner`, :102); Lensa calls neither (`grep -i 'withdraw|burn|redeem'` over zeto.ts and flows.ts -> no hit).
- Transfer: the UTXO owner proves with the node's prover; nullifiers hide the input owner, so BI cannot name an unreported sender (besu/zeto/src/bi-report.ts:213-216 `unknown-input-owner`).
- Supply control: BI only. Units: integer units, `PRICE_PER_UNIT = 1_000_000n` (frontend/server/src/domain.ts:14); on-chain `decimals()` is 4 but no adapter reads it; besu/zeto/src/instrument.ts:146-147 says "Zeto has no decimals of its own ... 1 unit = 1 rupiah", which is not what the chain reports.
