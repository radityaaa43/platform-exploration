## Conventions
- RED/GREEN: the "RED (before)" and "GREEN (after)" columns are the quoted lines qa must see. A row without a RED line is marked "not testable" with the reason.
- Fresh evidence: runtime verdicts use a tx made after the step's rollout. Served-build check before any Lensa run: `git -C frontend rev-list --count HEAD..origin/main` = 0 and `systemctl --user show lensa.service -p ActiveEnterTimestamp` after the last checkout update; else "stale build", no run.
- Namespaces: BEFORE `fabricx` (cluster 1; `fabricx-bi/-bank-a/-bank-b/-bank-c` on cluster 1 are multiregion, the cluster-2 `fabricx-bank-c` is foreign and never touched). AFTER `rd-fabricx-bi`, `rd-fabricx-bank-a`, `rd-fabricx-bank-b` (cluster 1), `rd-fabricx-bank-c` (cluster 2). qa uses each org's OWN kubeconfig (an output of S1), read-only (`get`, `describe`, `logs`, `auth can-i`; `exec` only for a single `psql -c 'select'`/`ls`).
- Lock/cap: a flow is a live write. `flock /tmp/lensa-paladin.lock` around ONE detached run, demo amounts, serial, lead GO, binding cap from the brief; release only by killing the holder qa started. A BI-down transfer takes ~267 s (C:105); Envoy route cap 300 s, Lensa `GW_CALL_MS` 305 s, `txDeadlineMs` 745 s (preserved by every step, PLAN header).
- BI-balance proof (flow steps S4, S14, S15, S17, S18, S19, S20; S14 and S20 are CLUSTER-OP live writes under flock): `frontend/web/e2e/flows/bi-delta.ts` fabricx: rd-issue 0/0, rd-transfer 0/0, dfabi-issue 0/0, dfabi-transfer 0/0, dvp 0/0, award RD +1,000,000 / DFABI 0. Command: `npx playwright test -c playwright.flows.config.ts e2e/flows/fabricx.flows.spec.ts` (worktree); expect `6 passed` and one `BI-DELTA fabricx <flow> <RD|DFABI>: PASS` line per cell. On the NEW ledger (S14 re-issues) the S20 proof is: sum of the four `balance` ops = BI issued total.
- Service-stop checks (one org or BI down): NOT run by qa (cluster write; evidence = lead's window under the step's own CLUSTER-OP GO).
- Health: `env -u KUBECONFIG ROOT=$PWD bash agents/ops/post-reboot-check.sh` with `NAMESPACES` set to the live set for the phase; expect `rc=0`, no `FAIL` (today `PASS pods fabricx 42 pods ok`).
